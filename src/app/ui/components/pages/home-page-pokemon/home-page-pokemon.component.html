Portifolio Pokedex

Este projeto é uma Pokedex interativa desenvolvida com Angular, utilizando a Poke API V2 para obter informações detalhadas sobre os Pokémon. Além disso, o Chart.js foi integrado para visualizar estatísticas dos Pokémon por meio de gráficos dinâmicos, proporcionando uma experiência visual rica e intuitiva. Com um design responsivo e moderno, esta Pokedex permite buscas eficientes, filtragem personalizada e exibição de dados em tempo real. Ideal para fãs da franquia que desejam explorar o universo Pokémon de maneira interativa!

Tecnologias usadas no Portifolio:

Atualmente, desenvolvo aplicações web utilizando Angular, um poderoso framework para construção de interfaces dinâmicas e escaláveis. Com RxJS, gerencio operações assíncronas e manipulação de dados reativos de forma eficiente. As integrações com APIs REST garantem comunicação fluida entre o front-end e os serviços back-end. O uso de SCSS permite estilizações avançadas e organizadas, enquanto o Angular Material proporciona componentes modernos e acessíveis para uma interface intuitiva. Além disso, foco na construção de um front-end responsivo, garantindo uma experiência fluida em diferentes dispositivos.

Porque o tema de Pokémon?

Escolhi Pokémon como tema para este projeto porque a franquia sempre me inspirou com seu universo vasto e envolvente. Utilizando a Poke API V2, consigo consumir dados detalhados dos Pokémon e aplicar minha criatividade para transformar essas informações em elementos visuais, animações e gráficos interativos. O uso de tecnologias como Angular e Chart.js me permite representar estatísticas de forma dinâmica, tornando a experiência mais intuitiva e envolvente. Assim, minha paixão pela franquia serve como catalisador para inovação, unindo entretenimento e desenvolvimento web em um projeto único.
